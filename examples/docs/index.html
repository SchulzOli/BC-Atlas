Create a new Warehouse Request

Warehouse requests

Use this guide to create a new Warehouse Request.

Before you start

  • Required permission: WAREHOUSE PROCESS
  • Required state: No warehouse request exists for entry number 10000.

Steps

The values below are examples from the automated UI test. Use values appropriate for your environment.

  1. Choose the 🔍 icon, enter Warehouse Requests, and then choose the related link. Choose New to create a record.
  2. In the Entry No. field, enter a value, for example 10000.Specifies the number that identifies the warehouse request.
  3. In the Description field, enter a value, for example Receive summer stock.Specifies what the warehouse needs to do.
  4. Close the Warehouse Requests page. Business Central saves your changes.

What should happen

  • The warehouse request is saved with the entered description.

Process an existing warehouse request from the request list

Warehouse requests

Use this guide to process an existing warehouse request from the request list.

Before you start

  • Required permission: WAREHOUSE PROCESS
  • Master data: A warehouse request exists and is not processed.
  • Complete Create a new Warehouse Request first.

Steps

  1. Choose the 🔍 icon, enter Warehouse Requests, and then choose the related link.
  2. Select the record you want to work with.
  3. Choose the Process action.Process the selected warehouse request and mark it as processed.
  4. Close the Warehouse Requests page. Business Central saves your changes.

What should happen

  • The warehouse request is marked as processed.
