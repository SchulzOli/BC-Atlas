# Create an EDI partner

Use this procedure to create a basic EDI trading partner with a code and name.

## Prerequisites

- You are signed in to the **CRONUS DE** company.
- You have permission to create EDI partners.

## Procedure

1. On the **EDI Platform** role center, select **EDI Partners**.
2. On the **EDI Partners** page, select **New**.
3. In **Partner Code**, enter the unique code for the partner.
4. In **Name**, enter the partner's display name.
5. Select **Back** to return to the partner list.

Business Central saves the partner automatically.

## Result

The new code and name appear in the **EDI Partners** list. The partner is not
blocked, and no message profiles, identities, source mappings, or outbound
profiles are configured yet.

## Verified example

- Partner code: `AI-DOC-0729`
- Name: `AI Documentation Dry Run`
- Company: `CRONUS DE`
