# Sicherheitsrichtlinie

Bitte melden Sie Schwachstellen **nicht** über öffentliche Issues, sondern vertraulich an die
Projektverantwortlichen. Geben Sie betroffene Version, Reproduktionsschritte und mögliche Auswirkungen an.
Wir bestätigen den Eingang innerhalb von 3 Werktagen.

Das Sicherheitskonzept mit Bedrohungsmodell und Restrisiken steht in [docs/SICHERHEIT.md](docs/SICHERHEIT.md).
